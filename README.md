## 产品设计

「合拍」希望让每笔钱、每次值日、每件公共物品和每条共同约定都有清晰的负责人、状态和记录，减少合租生活中因信息不透明造成的摩擦。

- **费用 AA**：记录共同支出、自动均摊并标记结清状态
- **清洁排班**：查看本周值日安排，一键完成或申请换班
- **公共物品**：登记库存、低库存提醒，并可“补货并记账”
- **室友公约**：共同提议、逐人确认，形成明确生活边界

核心演示闭环是“补货并记账”：公共物品补货后，库存状态与 AA 账本会同步更新。

## 使用说明

这是一个可交互的前端产品原型，数据通过浏览器本地存储保存，不包含真实个人信息、支付能力或远程数据库。可使用页面左下角的“重置演示”恢复初始状态。
